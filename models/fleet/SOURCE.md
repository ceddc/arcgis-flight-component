# Demo aircraft assets

This folder contains the GLB models and preview images used by the aircraft
demo: classic propeller plane, Super Jet, Space Jet, and paraglider. These
showcase files are not included in the installed flight component package;
its default classic body, propeller, and boost assets come from
`src/assets/aircraft/`.
Copy any showcase models you want into your application and set their asset
URLs in the component configuration. See
[Custom aircraft](../../../docs/custom-aircraft.md) for the configuration
fields and model requirements.

The original 3D assets were created by the repository author. The demo's
flight handling, speed settings, and effects are implemented separately in
this repository and are not part of the model files.
